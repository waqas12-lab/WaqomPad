# 📖 Overview

**WaqomPad** is a professional lightweight desktop text editor developed using **Java Swing**.

Inspired by the simplicity of traditional editors like Windows Notepad, WaqomPad provides a clean, fast, and native editing experience while adding modern productivity features such as **dark mode, advanced search tools, font customization, zoom controls, and document management**.

Designed for **Windows, macOS, and Linux**, WaqomPad focuses on performance, simplicity, and usability with **zero external dependencies**.

# ⚙️ Requirements

Before running WaqomPad, install:

* Java Development Kit (JDK) 17 or newer

Check Java installation:

```bash
java -version
```

---

# ▶️ Build & Run

Clone the repository:

```bash
git clone https://github.com/yourusername/WaqomPad.git
```

Navigate to the project:

```bash
cd WaqomPad
```

Compile:

```bash
javac src/Waqompad.java
```

Run:

```bash
java -cp src Waqompad
```
