## ✨ Overview

**WaqomPad** is a professional Java Swing desktop text editor inspired by Windows Notepad. It provides a clean, native-looking experience across **Windows, macOS, and Linux** while remaining lightweight and fast.

---

## 🚀 Features

### 📂 File Operations

* New
* New Window
* Open
* Save
* Save As
* Print Support
* Multiple Windows
* Unsaved Changes Warning

### ✏️ Editing

* Undo / Redo
* Cut / Copy / Paste
* Delete
* Select All
* Find
* Find Next / Previous
* Replace
* Go To Line
* Insert Time & Date

### 🎨 Formatting

* Word Wrap
* Font Chooser
* Zoom In
* Zoom Out
* Restore Default Zoom

### 🖥️ Native Experience

* Native OS Title Bar
* Native Window Controls
* No Custom Decorations
* System Look & Feel
* Cross-Platform Support

### 📊 Additional

* Status Bar
* Line & Column Tracking
* Current File Name in Window Title
* Unsaved Changes Indicator (*)
* Lightweight and Fast

---

## ⚙️ Requirements

* Java JDK 17+
* Java Swing
* No External Libraries
